LƯU Ý PHẠM VI
- Hệ số tính offline rồi cấu hình vào RTL; README chưa yêu cầu adaptive LMS chạy thời gian thực.
- Thành viên phụ trách RTL từng khối; bạn phụ trách interface chung, model, hệ số, tích hợp và kiểm chứng toàn hệ thống.
- So từng mẫu có nhiễu cần cùng vector nhiễu hoặc model đúng bộ sinh RTL; so BER thống kê cần ghi seed và số mẫu.
- BER = số bit lỗi / tổng bit hợp lệ; SER = số symbol lỗi / tổng symbol hợp lệ, sau khi căn latency và bỏ giai đoạn khởi động.
- Mốc trên 200 MHz trong README là mục tiêu; chỉ báo cáo đạt khi có kết quả timing phù hợp.
